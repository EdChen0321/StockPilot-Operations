# KOL 分析指南

[回到專案首頁](../README.md) · [訂單與銷售指南](orders-sales.md)

## 使用目標

這份指南說明如何準備 KOL 商品對照、匯入 KOL 訂單 Excel、核對 UTM 歸屬並查看統計。KOL Excel 分析資料與一般銷售訂單有各自的來源與口徑，不應直接把兩套數字相加。

## 前置條件

- 準備唯讀的商品對照 Excel，需有「產品代號」「產品名稱」「產品類型」欄。可在啟動時指定商品對照檔；未指定時，系統查找本專案的 `.local/kol-products.xlsx`。
- 準備要分析的 KOL 訂單 `.xlsx`，保留原始檔。檔案須在 2 MB 以內、只有一個可見工作表，單批最多 5,000 筆資料列。
- 確認訂單來源與要使用的 KOL／UTM 標記；未知標記應先查原始資料，不靠猜測歸屬。

## 操作流程

```text
準備商品對照與 KOL 設定 → 上傳 Excel 預覽 → 核對 UTM 與錯誤 → 確認匯入 → 查看統計
```

1. 進入「報表與分析 → KOL 分析」（Step 1），先核對 KOL 設定及其 UTM medium 對應。
2. 在 KOL 匯入工作區選擇來源和 Excel，送出預覽。檢查商品對照、排除的訂單、錯誤列，以及尚未匹配的 UTM。
3. 確認預覽內容與來源檔相符後，按「確認匯入」。預覽尚未確認前，不應把統計視為正式結果。
4. 到 KOL 統計選擇期間、來源、KOL 或 UTM 篩選，核對訂單數、金額與商品結果；需要時回看原匯入批次。

如果送出後連線中斷或結果不明，先用頁面提供的恢復／查看批次功能查詢原操作，再決定是否重試。不要換檔名建立另一批相同資料。

## 核對重點

| 項目 | 核對方式 |
| --- | --- |
| 商品 | 產品代號與唯讀對照表一致，未知商品先補正來源資料 |
| UTM 歸屬 | 未知 UTM、未填 UTM 與已匹配 KOL 分開查看 |
| 訂單狀態 | 有效、取消及排除訂單分開計算，不把取消訂單當銷售 |
| 金額 | 原始檔缺少金額時保留缺值，不視為零元 |
| 批次 | 同一來源檔的預覽、確認與重試結果可追查 |

## 完成後驗證

- 匯入批次顯示已確認，錯誤與排除資料符合原始 Excel。
- 未匹配及未填 UTM 數量可單獨核對，不被算入已知 KOL 成效。
- 相同篩選條件下，統計訂單數與明細筆數可回到來源單核對。

## 常見問題與排錯（Troubleshooting）

| 狀況 | 先核對 |
| --- | --- |
| 找不到商品對照表 | 是否提供含必要三欄的檔案，以及檔案位置是否正確 |
| Excel 無法預覽 | 是否為單一可見工作表、檔案未超過 2 MB 或 5,000 筆資料列 |
| UTM 未歸屬 | 先查來源標記與 KOL 設定，再決定如何對應；不要直接猜測 |
| 確認結果不明 | 使用批次恢復或查詢功能核對原操作，避免建立重複批次 |

本指南依 2026-11-04 的 KOL 匯入與分析程式碼整理。新拆出的營運包尚未完成真實瀏覽器全流程驗收；Excel 欄位、歸屬規則或統計口徑變更時應同步更新本頁。
